# Uber Ride Analytics Dashboard | Power BI

## Project Overview

The Uber Ride Analytics Dashboard is a Data Analytics project developed using Microsoft Power BI.

The main objective of this project is to analyze Uber ride booking data and generate meaningful business insights related to bookings, revenue, vehicle performance, customer behavior, and location-based trends.

## Project Objectives

- Analyze completed and lost ride bookings.
- Understand monthly booking trends.
- Analyze revenue generation.
- Compare vehicle-wise performance.
- Understand customer and rider behavior.
- Identify popular pickup and drop locations.
- Analyze customer payment preferences.
- Monitor customer and driver ratings.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning
- Data Visualization
- Data Analytics
